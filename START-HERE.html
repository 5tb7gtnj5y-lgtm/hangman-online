Hangman Online is ready to publish.

Create a room, invite a friend, watch their guesses live, then swap turns automatically.

Not live yet. This package needs publishing to your Cloudflare account. Your original game is backed up and unchanged.

Publish on a computer

  1. Install Node.js LTS from nodejs.org if needed.
  2. Extract the ZIP and open the Hangman-Online folder. It contains package.json and wrangler.jsonc.
  3. On Windows, type cmd in that folder’s File Explorer address bar and press Enter. On Mac, open Terminal in the folder.
  4. Run the following commands one at a time:
    npm install
npx wrangler login
npm run deploy
    Sign into your existing Cloudflare account when the browser opens.
  5. Open the real website address printed after deployment. Share it with the other player.

Keep Cloudflare Workers on its Free plan. There is no paid AI service or API key to set up.

Play

  1. Create a game and share its link or code.
  2. Your friend opens it on their phone and joins.
  3. Send your secret word. Your friend guesses while you watch.
  4. After the round ends, the roles swap automatically.

For the GitHub publishing option, testing details and backup instructions, open README.md in this folder.

After publishing, check one full round on two real phones. The server passed local Cloudflare runtime tests; live iPhone browser testing remains to be done.
